# Ludicrum - Magnetically connecting customizable videogame interfaces

## Abstract
Ludicrum is a system of magnetically connecting tiles that allow users and developers to build custom, physical interfaces for specific games and purposes. With a universal set of recognized tiles, developers can specify which tiles are needed to play a game as intended, and user's can configure the shape and style of their interface based on their needs and comfort. This achieves the satisfaction and immersion achieved by games with dedicated hardware (ie. Guitar Hero) while being applicable to a wider variety and range of games.
